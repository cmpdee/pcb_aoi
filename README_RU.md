# pcb_aoi

`pcb_aoi` — набор инструментов для оптического контроля печатных плат с участием оператора.

Проект сразу строится модульно, чтобы нынешний Visual Comparator не пришлось потом переделывать в монолит при добавлении камеры или контроля установленных компонентов.

## Текущий модуль: Visual Comparator

**Visual Comparator** совмещает скан/PDF платы с производственными данными и накладывает геометрию меди/сверловки для визуальной проверки.

Сейчас реализовано:

- PNG/JPEG/TIFF/BMP и многостраничные PDF с предпросмотром и выбором страниц;
- Gerber + Excellon;
- CAMvu/CAM350 text database;
- автоматическая регистрация Top/Bottom;
- автоматическое зеркалирование Bottom;
- разрешение неоднозначных поворотов по Profile и полной карте отверстий;
- поддержка Altium `.EXTREP` для определения контура `Board Shape` с произвольным расширением `.GMnn`;
- определение масштаба сокращённых координат Excellon `METRIC,LZ` (4:3 / 4:4);
- отдельный учёт фрезерованных пазов, без принятия траекторий фрезеровки за круглые отверстия;
- отверстия меньше ~2 пикселей помечаются как оптически неопределённые, а не как дефекты;
- наложение меди с регулировкой прозрачности;
- отображение PTH / VIA под маской / NPTH при наличии solder-mask;
- ручная коррекция якорей;
- экспорт текущего вида;
- **переключение интерфейса Русский / English без перезапуска**.

> Текущая версия: **v0.15.15, pre-1.0**. Программа помогает оператору и пока не является автоматической системой решения «годен/брак».

## Архитектура проекта

GitHub-репозиторий называется **`pcb_aoi`**. Нынешний Visual Comparator — первый самостоятельный модуль.

Планируемая структура:

- **Visual Comparator** — скан/PDF ↔ Gerber/CAM, уже работает;
- **LiveCam** — видеопоток с камеры и автоматическое наложение Gerber, следующая крупная ветка;
- **Component Inspection** — возможный будущий модуль проверки установки компонентов.

В v0.15.15 корневой `pcb_aoi.py` сразу запускает Visual Comparator. Позже вместо прямого запуска можно добавить стартовое меню выбора модуля, не меняя код самого Visual Comparator.

## Запуск Windows

1. Установить 64-битный Python 3.12 (рекомендуется) или 3.13.
2. Запустить `run_windows.bat`.
3. Выбрать скан/PDF; если страниц несколько, нажать **Preview… / Просмотр…**, пролистать и выбрать нужную.
4. Оставить **Источник = Gerber**, выбрать папку Gerber/Excellon и сторону Top/Bottom.
5. Нажать **АНАЛИЗ**.

При первом запуске автоматически создаётся `.venv` и устанавливаются зависимости.

## Linux / macOS

## Выбор языка

Переключатель **Language / Язык** находится в правом нижнем углу окна. По умолчанию выбран **English**:

- Русский
- English

Интерфейс переключается на лету, перезапуск не требуется. Общепринятые технические обозначения `Top`, `Bottom`, `Gerber`, `CAM`, `Overlay`, `Anchors` не переводятся.

## Распознавание производственных файлов

Выбор файлов в Gerber-папке выполняется по содержимому, стандартным расширениям и общим соглашениям имён. Нет привязки к конкретному номеру платы, имени проекта или абсолютному пути.

В частности:

- Top copper: `.gtl`, X2 `FileFunction=Copper,...,Top`, общие Top/Copper имена;
- Bottom copper: `.gbl`, X2 `FileFunction=Copper,...,Bot`, общие Bottom/Copper имена;
- solder mask: `.gts` / `.gbs`, X2 и общие mask-имена;
- Profile: X2 Profile, `profile`, `outline`, `edge_cuts` и похожие общие названия;
- drill: `.drl`, `.xln`, `.exc`, `.drd`, поддерживаемые ASCII `.txt`.

При наличии отчёта Altium `.EXTREP` слой `Board Shape` определяется по назначению, даже если экспортирован как `.GM14`, `.GM27` и т. п.

Если в Altium-экспорте одновременно лежат бинарный `.DRL` и читаемый ASCII `.TXT` с тем же stem, выбирается ASCII-файл. Поддерживаются PTH/NPTH группы в одном drill-файле.

Для старых CAM350 text database оставлена compatibility-эвристика ширины дорожек, но она определяется по **сигнатуре содержимого**, а не по названию платы/файла.

## Структура репозитория

```text
pcb_aoi.py                         # текущая точка входа проекта
visual_comparator.py              # прямой запуск Visual Comparator
pcb_aoi/
  __init__.py
  visual_comparator/
    app.py                        # GUI
    core.py                       # Gerber/Excellon, регистрация, рендер
run_windows.bat
run_linux_macos.sh
build_windows_exe.bat
requirements.txt
```

## Сборка Windows EXE

Запустить:

```bat
build_windows_exe.bat
```

Результат: `dist\PCB_AOI.exe`.
